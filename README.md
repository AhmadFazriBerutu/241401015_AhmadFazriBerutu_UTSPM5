## B. Informasi Aplikasi
- **Nama Aplikasi:** Kuis Akademi Shrek
- **Deskripsi Singkat:** Aplikasi kuis pilihan ganda bertema RPG fantasi "Soul Land" untuk menguji pengetahuan pengguna seputar dunia roh bela diri. Aplikasi dilengkapi dengan sistem kalkulasi tingkatan (Rank) dinamis berdasarkan skor akhir pengguna.
- **Fitur-fitur yang Tersedia:**
  - Input nama pengguna (Spirit Master).
  - 10 pertanyaan pilihan ganda dinamis.
  - *State Management* (Provider) yang menjaga skor dan nomor soal tetap aman saat layar diputar.
  - Umpan balik visual interaktif (warna hijau/merah) dengan jeda timer saat menjawab soal.
  - *Progress bar* indikator soal.
  - Kalkulasi dan klasifikasi Rank (Tingkatan) dari 'Soul Trainee' hingga 'God' di layar hasil.
  - Transisi halaman kustom (*fade & slide*).
